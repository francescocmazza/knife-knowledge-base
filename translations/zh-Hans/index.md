# Xinzuo 知识库

一把厨刀看起来很简单:一个刀柄、一片刀身和一条刃口。但它的表现并不简单。钢材、热处理、刀身几何形状、磨刀方式、平衡感与使用者的技巧共同发挥作用。

这是 Xinzuo 的知识库：一份介绍厨刀材料、结构、生产选择、使用与保养的实用指南。它面向家庭烹饪爱好者、厨师、Xinzuo 销售团队、经销商、零售人员、内容创作者，以及所有希望了解为何两把外观相似的刀在使用中会有不同感受的读者。

本指南注重实用性而非学术性。它从 Xinzuo 产品中的特征出发，并将其置于更广泛的制刀背景中。其他钢材、材料、制造商和传统会在有助于澄清比较时被讨论；Xinzuo 是本知识库的参照点，而不是偶尔出现的例子。

> 一把刀从不由单一特性所定义。真正有意义的问题永远是:它的各项特性如何为某项具体任务和某位具体使用者协同发挥作用。

## 推荐阅读顺序

每一章都可以独立阅读,但按照以下顺序阅读,新读者会更容易理解本主题。

### 1. 从几何形状开始

- [单面刃与双面刃](04-geometry-and-bevels/single-and-double-bevels.md)
- [刀具类型与切割风格](05-knife-types/overview.md)

先了解刀是如何接触食材的。刃面、刃形、刀身高度、弧度和厚度比冶金学更容易被直观理解,它们也解释了为什么一把刀在切割时可能会跑偏、可能会摇切、剁切、滑切,或以不同方式使食材分离。

### 2. 了解如何描述钢材性能

- [刀具钢材的五个维度](01-foundations/five-dimensions-of-knife-steel.md)
- [Xinzuo 刀具钢材——产品组合指南](02-steels-and-metallurgy/xinzuo-blade-steels.md)
- [合金元素——实用指南](02-steels-and-metallurgy/alloying-elements.md)
- [Xinzuo 刀柄材料——产品组合指南](02-steels-and-metallurgy/xinzuo-handle-materials.md)

理解刀具几何之后，钢材规格会更有意义。这些章节解释硬度、易磨性、耐腐蚀性、韧性与微观组织细密度，并将这些概念应用于 Xinzuo 产品组合所使用的钢材和刀柄材料。

### 3. 理解刀身构造

- [大马士革钢——构造、外观与性能](03-blade-construction/damascus-steel.md)
- [全大马士革刀身的自磨锐效应](03-blade-construction/self-sharpening-full-damascus.md)

这些章节区分了覆层花纹、全层锻焊构造、历史上的wootz钢,以及仅在表面模仿花纹的装饰工艺。它们还说明了当层材真正到达刃尖时,交替钢材如何影响刃口磨损。

### 4. 安全使用刀具

- [安全使用与携带](08-use-and-safety/safe-use-and-carrying.md)

一把合适又锋利的刀更容易掌控,但安全取决于完整的操作方法:稳固的砧板与食材、正确的握刀方式、可控的动作、合适的切割面、安全的携带方式与妥善的收纳。

### 5. 最后学习磨刀

- [准备水磨石](10-sharpening/whetstone-preparation.md)
- [理解毛刺](10-sharpening/the-burr.md)
- [实用磨刀流程](10-sharpening/basic-sharpening-process.md)

一旦读者了解了刃面与刃尖是什么,磨刀就会变得容易得多。这个顺序是刻意安排的:先准备磨石,再理解毛刺,最后学习完整的流程。

## 本首版涵盖的内容

本版解释:

- 单面刃与双面刃几何形状如何改变切割表现;
- 主要刀型的轮廓如何支持摇切、推切、剁切、滑切与精细作业;
- 如何比较不同钢材,而不是把某一项数值当作通用的质量评分;
- 主要的Xinzuo刀片钢,其典型的目录硬度范围以及实际的权衡;
- (a) Xinzuo使用的主要天然和工程处理材料;
- 主要合金元素各自的贡献;
- 覆层大马士革、全大马士革与表面装饰之间的区别;
- 被称为"自磨锐效应"的差异化磨损机制;
- 安全使用、携带、清洗、运输与收纳;
- 磨石的准备、平整度、泥浆与磨屑;
- 毛刺的形成、检测与去除;
- 完整的双面刃磨刀流程。

## 核心理念

> 钢材创造可能性。热处理将其开发出来。几何形状将其转化为切割表现。磨刀恢复刃口。技巧决定使用者的实际体验。

这一关系正是贯穿本知识库每一章节的主线。

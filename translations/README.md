# Translations

This directory contains localized versions derived from the English source in `content/en/`.

## Rules

- English is the only source-of-truth language.
- Translations may improve clarity, grammar, and natural phrasing, but must not introduce new technical or commercial claims.
- Meaning changes must first be approved in English.
- Japanese, Simplified Chinese, and Traditional Chinese require terminology review by a competent speaker familiar with kitchen knives.
- Each localized page should record the English source revision or commit.

## Initial priority languages

1. Italian
2. Spanish
3. German
4. French
5. Simplified Chinese
6. Traditional Chinese
7. Japanese

Additional locale codes may be added without changing the repository architecture.
